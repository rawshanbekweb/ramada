# Инструкция для ресепшн

Вся работа — в Telegram-боте. При первом запуске отправьте боту код от руководителя: `/start КОД`.

## Смена

**Без открытой смены нельзя заселять гостей и принимать оплату.**

- **Открыть:** «💵 Смена» → пересчитайте наличные в кассе и введите сумму.
- **Закрыть:** «💵 Смена» → «Закрыть смену» → пересчитайте наличные и введите сумму.
- Система не показывает «ожидаемую» сумму (слепой пересчёт). Расхождение автоматически уходит руководителю.

## Новый гость

1. «🆕 Новый гость» → выберите номер (только свободные и чистые).
2. Число ночей.
3. ФИО гостя, серия и номер паспорта, **фото паспорта** (обязательно).
4. **Телефон гостя** — на него придёт SMS.
5. «Есть смартфон?»
   - **Да** — обычный порядок.
   - **Нет** — оплата только с номером чека, 3-й этап на следующий день подтверждает горничная.
6. «Гость на месте?»
   - **Да** — обычный случай.
   - **Нет** — бронь заранее. Когда гость придёт, нажмите «🚶 Гость пришёл».
7. «Нужна скидка?»
   - Скидка — только с одобрения руководства.
   - Нет ответа за 10 минут — отказ.
   - SMS гостю уйдёт после решения.
8. Проверьте и нажмите «✅ Подтвердить».

**Цену вводите не вы, и изменить её нельзя** — её считает система по тарифу.

## Подтверждение гостя и оплата

1. Гость открывает ссылку из SMS и нажимает **«Подтверждаю»**. Скажите ему: «Вам пришло SMS, откройте и подтвердите».
2. Примите оплату и выдайте **фискальный чек**.
3. В боте: карточка гостя → «💵 Наличные» или «💳 Терминал» → сумма → **номер чека**. Без номера чека оплата не принимается.
4. Когда есть и подтверждение гостя, и полная оплата, бот пишет **«🔑 Выдайте ключ»**.

**Важно:**
- Нажатие «🔑 Выдать ключ» без подтверждения и оплаты отклоняется, руководитель получает сообщение.
- Если введена меньшая сумма, бронь не подтверждается и руководитель получает сообщение.
- Гость получает SMS-чек о каждой оплате и видит сумму на своей странице.

## После выдачи ключа

- **Камера:** гость должен дойти до своего номера в течение 30 минут. Камера фиксирует это сама (2/3).
- **QR в номере:** гость сканирует QR-табличку и получает пароль Wi-Fi (3/3).
- **Пароль Wi-Fi устно не сообщайте** — он выдаётся только через QR.

## Список гостей («📋 Гости»)

Значки: ⏳ — ждём подтверждения, 🟡 — 1/3, 🟢 — 2/3, ✅ — 3/3.

| Кнопка | Что делает |
|---|---|
| 💵 Наличные / 💳 Терминал | Ввод оплаты с номером чека |
| 🔑 Выдать ключ | Отметка о выдаче ключа |
| 🚶 Гость пришёл | Для предварительной брони — открывает окно камеры |
| 📨 SMS повторно | Повторно отправить ссылку |
| ➕ Продлить | Гость подтверждает новую сумму и платит |
| 🔁 Сменить номер | Гость подтверждает, доплачивает разницу, камера проверяет новый номер |
| 🚪 Выезд | Поздний выезд считается автоматически; остаток оплачивается до выезда |
| 🕓 Оплатить позже | Только с разрешения владельца |
| 🗑 Отменить | Только с причиной и через одобрение руководства; удалить бронь нельзя |

## Частые случаи

- **У гостя нет смартфона:** создайте бронь «без смартфона» и введите оплату с чеком.
- **Несколько гостей в одном номере:** бронь на один телефон. Спутники подтверждают QR последними 4 цифрами этого телефона.
- **SMS не пришло:** нажмите «📨 SMS повторно» и проверьте номер.

## Ключница

Иногда бот просит фото ключницы. Сразу отправьте общий снимок.
